# Persistent gameplay context

These instructions apply whenever an agent plays a game or operates another ongoing interactive setting in this workspace.

## Start of a playthrough

1. Find the matching directory under `.agent-local/`.
2. Read its play guide, action/tool playbook, story or state log, and any other relevant notes before acting.
3. Resume the live state and established story. Do not restart, recreate, or discard consequences merely to simplify the session.
4. Reuse proven procedures from earlier playthroughs before improvising a new low-level approach.

If a setting has no directory yet, create `.agent-local/<setting>/` and begin a concise state log and reusable action playbook.

## End of every gameplay session or setting handoff

Every playthrough must build on the last. Before finishing:

1. Pause or otherwise leave the interactive state at a safe, intentional handoff point.
2. Update the setting's story/state log with the exact current scene, time, protagonist state, urgent pressures, queued actions, resources, relationship changes, completed beats, and useful next choices.
3. Update the reusable play or action documentation with every genuinely new technique learned during the session. Include enough executable detail for another agent to repeat it, plus validation and safety guardrails.
4. Preserve prior lessons. Correct entries that proved wrong, but do not replace accumulated knowledge with a session-only summary.
5. Keep one-off narrative events in the story/state log and generalizable operating knowledge in the action playbook.

Do this closeout even when the user does not explicitly request documentation.
